# yunmi
## 云觅是一款数据处理软件，集成了数据采集，数据分析，数据发布等诸多功能
## 单机模式仅支持数据采集功能，如数据量巨大或需要数据分析等功能，建议使用集群采集功能，请先部署服务器端，地址如下：
## https://github.com/nrz123/yunmi-server

## 编译或调试需要nodejs环境，请先在项目目录运行npm install命令安装依赖

## 编译：在项目目录运行 npm run dist命令（windows），npm run linux命令（linux系统），其它系统请自行修改package.json文件

## 调试：该项目使用electron+react框架，请在项目目录运行npm start命令后使用vscode进行调试
